# مشروع Business Manager — موقع ويب لإدارة البزنس والمبيعات والأرباح 🌸

موقع ويب شخصي متكامل وعصري لإدارة المشاريع التجارية لشخص واحد، يتيح متابعة شراء المنتجات، عمليات البيع، المصروفات التشغيلية، الإعلانات الممولة، حساب صافي الأرباح والخسائر بدقة، إدارة المخزون، وأرشفة البزنسات المغلقة.

المشروع مصمم بتقنيات الويب النقية **(HTML5 / CSS3 / Vanilla JavaScript)** ليعمل مباشرةً وبكفاءة فائقة على **GitHub Pages** وأي استضافة ويب ثابتة دون الحاجة إلى Node.js أو أدوات Build معقدة.

---

## 💎 المميزات الرئيسية

1. **تصميم أنثوي عصري مميز:**
   - لوحة ألوان راقية (الوردي الأساسي `#E85D9E`، الوردي الفاتح، البنفسجي، الذهبي، والأبيض).
   - واجهة عربية بالكامل بتنسيق RTL مع خط `Tajawal`.
   - بطاقات إحصائية عصرية، ورسوم بيانية تفاعلية عبر `Chart.js`.
   - متجاوب 100% مع الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.

2. **حسابات مالية دقيقة ومنع الازدواجية:**
   - حساب تكلفة القطعة الواحدة بدقة: `إجمالي تكلفة المخزون (بضاعة + شحن + جمارك) ÷ عدد القطع المشتراة`.
   - منع احتساب التكلفة مرتين عند الشراء بالدولار الأمريكي مع تحويل آلي بالدينار الليبي عبر سعر الصرف.
   - حساب تكلفة البضاعة المباعة (COGS) لحظياً لكل عملية بيع.
   - صافي الأرباح والخسائر = `صافي المبيعات - تكلفة البضاعة المباعة - المصروفات الإضافية`.
   - نسبة هامش الربح = `(صافي الربح ÷ صافي المبيعات) × 100`.
   - تتبع المبالغ المحصلة فعلاً والمبالغ المستحقة (الديون) من العملاء.

3. **إدارة المخزون الذكية:**
   - مراقبة حية للمخزون المتبقي لكل بزنس.
   - منع إتمام عمليات بيع تتجاوز الكمية المتوفرة بالمخزون.
   - حماية من تكرار تسجيل العمليات بالضغط المتكرر.

4. **إدارة متقدمة للبزنسات والأرشيف:**
   - إضافة وتعديل البزنسات النشطة وتتبع مكان الشراء (ليبيا أو الصين).
   - تتبع ميزانية الإعلانات الممولة والمصروف الفعلي منها.
   - إغلاق البزنس مع عرض ملخص مالي وكمية المخزون المتبقي، ونقله إلى الأرشيف.
   - إمكانية إعادة فتح البزنس في أي وقت بنقرة واحدة.

5. **تخزين البيانات وحمايتها (Firebase + Offline Fallback):**
   - يدعم **Firebase Cloud Firestore** لحفظ البيانات السحابية ومزامنتها لحظياً عبر مختلف الأجهزة.
   - يدعم **Firebase Authentication** لتأمين الدخول بحساب المالك الشخصي.
   - يوفر وضع تخزين محلي ذكي (LocalStorage Fallback) يعمل تلقائياً لتجربة الموقع والمعاينة دون انتظار أو تعقيد.

## 🔑 بيانات الدخول الافتراضية

عند فتح الموقع لأول مرة، يمكنك تسجيل الدخول مباشرة ببيانات المالك الشخصي الافتراضية:

- **البريد الإلكتروني:** `admin@business.com`
- **كلمة المرور:** `admin123`

*(يمكنك تغيير كلمة المرور والبريد أو ربط حساب Firebase الحقيقي بكل سهولة من قسم الإعدادات داخل الموقع).*

## 🚀 طريقة النشر على GitHub Pages

المشروع مبني بمسارات نسبية كاملة (`./css/style.css`، `./js/app.js`) ليعمل على GitHub Pages فوراً:

1. ارفعي ملفات المشروع إلى مستودع جديد على GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Business Manager"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPOSITORY_NAME.git
   git push -u origin main
   ```
2. ادخلي إلى إعدادات المستودع على GitHub: **Settings** -> **Pages**.
3. تحت قسم **Build and deployment**، اختاري **Branch: main** والمجلد **/(root)**، ثم اضغطي **Save**.
4. سيصبح موقعك متاحاً ويعمل خلال دقيقة على الرابط:  
   `https://USERNAME.github.io/REPOSITORY_NAME/`

## ☁️ خطوات ربط Firebase Realtime Database أونلاين

إذا أردتِ ربط حسابك السحابي ومزامنة البيانات اللحظية (Realtime) بين الهاتف والكمبيوتر:

1. افتحي [Firebase Console](https://console.firebase.google.com/) وأنشئي مشروعاً جديداً.
2. من القائمة الجانبية، فعّلي **Authentication** واختاري طريقة **Email/Password**.
3. أضيفي مستخدماً جديداً (بريدك وكلمة مرورك الخاصة).
4. من القائمة الجانبية، اضغطي على **Build** ثم **Realtime Database**، واضغطي **Create Database**.
5. اختاري موقع الخادم (مثلاً `United States` أو `Belgium`)، واختاري وضع الأمان **Locked mode** ثم اضغطي **Enable**.
6. في تبويب **Rules** بقاعدة بيانات **Realtime Database**، ضعي قواعد الأمان المحكمة لحصر الوصول لبريدك الشخصي فقط ومنع أي شخص آخر من قراءة أو تعديل أو سرقة البيانات:
   ```json
   {
     "rules": {
       ".read": "auth != null && auth.token.email === 'بريدك_المسجل@example.com'",
       ".write": "auth != null && auth.token.email === 'بريدك_المسجل@example.com'"
     }
   }
   ```
   *(استبدلي `بريدك_المسجل@example.com` بنفس البريد الإلكتروني الذي سجلتِ به في Firebase Authentication)*، ثم اضغطي **Publish**.
7. اذهبي إلى **Project Settings** (إعدادات المشروع ⚙️) وأضيفي تطبيق ويب للحصول على `firebaseConfig` (يتضمن `databaseURL` و `apiKey` و `projectId`).
8. افتحي موقعك، ثم توجهي إلى قسم **الإعدادات و Firebase** وألصقي المفاتيح هناك واضغطي **حفظ وتفعيل Firebase**، وستعمل قاعدة البيانات السحابية الحية لحظياً!
